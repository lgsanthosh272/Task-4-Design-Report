Task 4 – Complete Design Report
1. Project Title
3D CAD Design and Conceptual Analysis of a Small Mechanical Component
2. Project Overview
The objective of this project is to develop a practical 3D CAD model of a small mechanical component based on a defined design requirement.
The design is intended to be:
Simple and functional
Practical to manufacture
Suitable for 3D printing and prototyping
Easy to inspect and modify
Suitable for further analysis and testing
The project follows a basic engineering design process from problem definition through CAD development, conceptual analysis, and future improvements.
3. Problem Definition
A small mechanical support/fixture component is required for a practical mounting or supporting application.
The component should have a clear geometric form and sufficient material around its functional features. The design should also remain simple enough for manufacturing or rapid prototyping.
Design Requirements
Create a compact mechanical component.
Develop the component as a 3D CAD model.
Provide appropriate functional features.
Maintain sufficient material around important areas.
Keep the geometry simple and manufacturable.
Make the design suitable for prototype development.
Allow the model to be exported as STL or STEP where supported.
4. Design Concept
The selected concept is a small mechanical support/fixture component developed as a 3D solid model.
The design consists of a main body with functional geometric features intended for mounting, positioning, or supporting a mechanical assembly.
The concept focuses on:
Functional geometry
Simple construction
Manufacturability
Easy modification
Prototype suitability
5. CAD Development
The component was developed using an accessible CAD workflow.
The CAD development process included:
Defining the basic component requirements.
Creating the primary geometric profile.
Developing the 3D solid geometry.
Adding the required functional features.
Reviewing the model from different views.
Checking the overall geometry for prototype suitability.
Preparing the model for possible STL/STEP export.

8. Analysis Assumptions
The following assumptions were used for the conceptual analysis:
The applied load is within the intended small-component operating range.
The component is properly supported at its mounting locations.
The selected material is assumed to be suitable for the intended application.
No detailed fatigue, thermal, impact, or nonlinear analysis has been performed.
Final dimensions and material properties should be verified before real-world use.
9. Manufacturing Considerations
The design can be considered for rapid prototyping and 3D printing.
Important manufacturing considerations include:
Selecting a suitable material.
Checking minimum feature size.
Selecting an appropriate print orientation.
Checking hole and fastener clearances.
Checking wall thickness.
Inspecting the finished prototype.
Performing a fit and function test.
10. Next Steps
The following steps are planned for further development:
Verify all important dimensions.
Select and document the final material.
Define realistic loads and boundary conditions.
Perform detailed CAD/FEA analysis if required.
Export the final model as STL/STEP.
Create a physical prototype.
Test the prototype for fit and function.
Record test results.
Modify the CAD model based on testing.
Prepare the final validated design.
11. Conclusion
This project demonstrates a complete initial design workflow for a small mechanical component.
The process included problem definition, concept development, 3D CAD modelling, conceptual analysis, and identification of future development steps.
The completed CAD model provides a foundation for prototype manufacturing and further engineering validation.
Future work will focus on confirming dimensions, selecting the final material, performing detailed analysis, creating a physical prototype, and testing the component.
